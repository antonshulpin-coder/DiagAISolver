# Anton Harness

Локальный помощник для обучения, заметок и практической работы.

## Запуск

Откройте терминал в папке `G:\AntonHarness` и выполните:

```powershell
.\.venv\Scripts\python.exe launcher.py
```

## Где что хранится

- `config/settings.json` — путь к локальной Академии.
- `data/notes.json` — личные заметки пользователя.
- `src/` — исходный код Harness.
- `G:\Academy\Academy-Marketing` — единственный источник учебных материалов.

Harness читает материалы Академии, но не изменяет их. Если Академия будет перенесена, достаточно обновить путь `academy_root` в `config/settings.json`.
